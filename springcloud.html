1. Microservices Architecture | 微服务架构

Definition
Microservices architecture structures an application as a collection of loosely coupled, independently deployable small services that communicate over the network.
微服务架构把一个应用拆成多个松耦合、可独立部署的小服务，这些服务通过网络通信协作。
Business Capability
Each service focuses on a single business capability, runs in its own process, and usually manages its own database.
每个服务专注一个业务能力，运行在独立进程中，通常拥有自己的数据库。
Communication
Microservices communicate through well-defined APIs, usually lightweight HTTP-based RESTful APIs or asynchronous messaging.
微服务通过清晰定义的 API 通信，常见方式是轻量级 HTTP REST 接口，也可以使用异步消息。
Martin Fowler
The term “Microservices” is commonly associated with Martin Fowler.
“Microservices” 这个术语常与 Martin Fowler 联系在一起，考试常问是谁提出或推广。

Advantages | 优点

English中文
Independent scalability: each microservice can be scaled independently based on demand. 独立扩缩容：每个微服务可以按自己的访问量单独扩容，不必扩整个系统。
Technology flexibility: different services can use different languages, frameworks, or databases. 技术灵活：不同服务可以选不同语言、框架或数据库。
Faster development and deployment: teams can develop and release services independently. 开发部署更快：团队可以独立开发、测试、上线各自服务。
Fault isolation: failure in one service does not necessarily bring down the whole system. 故障隔离：某个服务出问题，不一定拖垮整个系统。

Challenges | 挑战

English中文
Network reliability and latency: remote calls introduce latency, partial failure, and network partition problems. 网络可靠性与延迟：远程调用会带来延迟、局部失败和网络分区问题。
Data consistency and distributed transactions: traditional ACID transactions are difficult across multiple services. 数据一致性与分布式事务：多个服务多个数据库之间很难直接使用传统 ACID 事务。
Operational complexity and monitoring: many services require logging, tracing, monitoring, and orchestration. 运维复杂度与监控：服务数量变多后，需要日志、链路追踪、监控和部署编排。

2. Spring Boot | Spring Boot 基础

Definition
Spring Boot is a framework built on top of the Spring Framework to simplify stand-alone, production-ready Spring application development.
Spring Boot 建立在 Spring Framework 之上，用来简化独立运行、可生产部署的 Spring 应用开发。
Convention over Configuration
Spring Boot simplifies Spring configuration using convention over configuration and automatic configuration.
Spring Boot 通过“约定优于配置”和自动配置减少繁琐配置。
Embedded Server
Spring Boot includes embedded Tomcat, Jetty, or Undertow, so no external application server is required.
Spring Boot 内置 Tomcat、Jetty 或 Undertow，不需要额外安装外部应用服务器。
Starter Dependencies
Starter dependencies such as spring-boot-starter-web simplify Maven or Gradle dependency configuration.
Starter 依赖（如 spring-boot-starter-web）简化 Maven/Gradle 依赖配置，并保证版本兼容。

Spring Boot Must-Remember | 必背点

English中文
Minimum Java version required by Spring Boot is Java 8.Spring Boot 最低要求 Java 8。
Spring Boot embeds Tomcat by default.Spring Boot 默认内嵌 Tomcat。
The main entry point is usually DemoApplication.java.主入口文件通常是 DemoApplication.java。
Configuration files are usually stored in src/main/resources.配置文件通常放在 src/main/resources。
Spring Boot supports application.properties and application.yml.Spring Boot 支持 application.properties 和 application.yml。
@RestController combines @Controller and @ResponseBody.@RestController 等于 @Controller + @ResponseBody。
@RequestMapping maps a URL path to a controller method.@RequestMapping 把 URL 路径映射到控制器方法。
Maven with pom.xml is used to manage dependencies.Maven 和 pom.xml 用于管理项目依赖。

3. Spring Cloud | Spring Cloud 角色

Role
Spring Cloud provides frameworks and tools built on Spring Boot to simplify microservices-based distributed systems.
Spring Cloud 基于 Spring Boot 提供一组框架和工具，用来简化微服务分布式系统开发。
Patterns
Spring Cloud handles common patterns such as service discovery, load balancing, circuit breaking, distributed configuration, and inter-service communication.
Spring Cloud 处理服务发现、负载均衡、熔断、分布式配置和服务间通信等常见模式。
Foundation
Spring Boot is the foundation for building Spring Cloud microservices.
Spring Boot 是构建 Spring Cloud 微服务的基础。
Version Naming
Spring Cloud versions use London Underground station names, such as Hoxton, Greenwich, and Finchley.
Spring Cloud 版本用伦敦地铁站命名，如 Hoxton、Greenwich、Finchley。
English: The Spring Cloud version used in this course is Hoxton.SR10.
中文：本课程使用的 Spring Cloud 版本是 Hoxton.SR10。

4. Core Components | 核心组件

ComponentEnglish中文
Eureka Used for service registry and discovery in Spring Cloud Netflix. 用于服务注册与发现，是 Spring Cloud Netflix 的组件。
Nacos Nacos is mainly used for service registry, discovery, and configuration management in Spring Cloud Alibaba. Nacos 在 Spring Cloud Alibaba 中主要负责服务注册发现和配置管理。
Ribbon Ribbon is a client-side load balancing library deployed inside every microservice. Ribbon 是客户端负载均衡组件，部署在每个微服务内部。
Hystrix Hystrix protects microservices using the Circuit Breaker pattern. Hystrix 使用熔断器模式保护微服务。
Feign Feign is a declarative web service client; remote calls look like local Java method calls. Feign 是声明式 Web 服务客户端，远程调用看起来像调用本地 Java 方法。
Gateway Spring Cloud Gateway is the single entry point that routes client requests to microservices. Spring Cloud Gateway 是统一入口，负责把客户端请求路由到各个微服务。
Config Spring Cloud Config provides centralized distributed configuration. Spring Cloud Config 提供集中式分布式配置管理。
Stream Spring Cloud Stream builds message-driven microservices using publish-subscribe messaging. Spring Cloud Stream 用发布订阅消息模型构建消息驱动微服务。

5. Configuration and Resilience | 配置与容错

1
bootstrap.yml is loaded before application.yml and usually has higher priority for bootstrap configuration.
bootstrap.yml 会在 application.yml 之前加载，通常用于启动阶段配置，优先级更高。
2
Hot update means configuration changes can take effect without restarting the microservice.
热更新表示配置变更可以在不重启微服务的情况下生效。
3
Hystrix has three circuit breaker states: Closed, Open, and Half-Open.
Hystrix 熔断器有三种状态：关闭、打开、半开。
4
When the circuit breaker is open, Hystrix immediately returns a fallback response without waiting.
当熔断器打开时，Hystrix 不再等待远程调用，而是立即返回 fallback 响应。

CAP Theorem | CAP 定理

According to the CAP theorem, a distributed system can guarantee at most two of Consistency, Availability, and Partition Tolerance at the same time.
根据 CAP 定理，分布式系统在一致性、可用性、分区容错性三者中，最多只能同时保证两个。

6. Spring Cloud Stream | 消息驱动

Definition
Spring Cloud Stream is a framework for building event-driven, message-driven microservice applications.
Spring Cloud Stream 是用于构建事件驱动、消息驱动微服务应用的框架。
Middleware
Spring Cloud Stream supports RabbitMQ and Kafka out of the box.
Spring Cloud Stream 默认支持 RabbitMQ 和 Kafka。
Abstraction
It provides an abstraction over messaging middleware so business code does not directly depend on a specific broker.
它对消息中间件做抽象，让业务代码不直接依赖具体消息系统。
Pattern
It commonly uses the publish-subscribe pattern for communication.
它常使用发布订阅模式进行通信。

8. True / False Corrections | 判断题纠错

StatementAnswer中文解释
Microservices architecture splits a large system into small, independently deployable services. True 微服务架构确实是把大系统拆成小型、可独立部署的服务。
Monolithic architecture has low coupling between modules. False 单体架构通常模块耦合较高，不是低耦合。
Spring Boot replaces the Spring Framework entirely. False Spring Boot 没有替代 Spring，而是在 Spring 之上简化开发。
Spring Boot requires an external Tomcat server before running an application. False Spring Boot 默认内嵌 Tomcat，不需要外部 Tomcat。
Services registered in Nacos send periodic heartbeat signals to show they are alive. True 注册到 Nacos 的服务会通过心跳表示自己仍然存活。
The CAP theorem says a distributed system can guarantee C, A, and P all at the same time. False CAP 定理说最多同时保证两项，不是三项都能保证。
Ribbon is deployed as a standalone server, separate from microservices. False Ribbon 是客户端负载均衡，部署在微服务内部，不是独立服务器。
Hystrix circuit breaker has three states: Closed, Open, and Half-Open. True Hystrix 熔断器状态包括关闭、打开、半开。
With Feign, calling a remote service becomes as simple as calling a local Java method. True Feign 的目标就是让远程调用像本地方法调用一样简单。
Local application.yml has higher priority than Nacos online configuration. True 参考中文复习资料：本地 application.yml 具有比 Nacos 在线配置更高的优先级。
